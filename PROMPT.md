# Goal

## Objective
Build a small, polished web app for people planning a short trip to Busan. The app should help users quickly choose what to do based on travel style, time available, and area of interest.

## Product Scenario
A traveler is visiting Busan for one day and wants a simple planner that recommends a route without needing to read long travel articles. They should be able to select a travel mood, see recommended places, and save a short itinerary.

## Requirements
- Create a working frontend app in this repository.
- Use a modern, lightweight setup that can run locally with a clear command.
- The first screen should be the usable trip-planning experience, not a marketing landing page.
- Include travel mood filters such as `Food`, `Ocean`, `Culture`, `Night View`, and `Relaxed`.
- Show a list or map-style layout of Busan places with short descriptions.
- Allow users to add places to a simple itinerary panel.
- Include at least 8 Busan places, such as Haeundae, Gwangalli, Gamcheon Culture Village, Jagalchi Market, Taejongdae, Songdo, BIFF Square, and Seomyeon.
- Make the layout responsive for mobile and desktop.
- Keep the UI clean, practical, and easy to scan.
- Add or update README instructions so a developer can install and run the project locally.

## Success Criteria
- The app runs locally without errors.
- Users can filter recommended places by travel mood.
- Users can add and remove places from an itinerary.
- The page looks complete on both mobile and desktop widths.
- README contains the run command and a short project description.

## Constraints
- Do not require a backend server or database.
- Do not use paid APIs.
- Keep the implementation simple enough for a hackathon prototype.
